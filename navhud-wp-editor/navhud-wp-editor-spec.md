# NavHUD WPエディタ 仕様

NavHUD（Android ナビアプリ）で読み込む WP（ウェイポイント）ファイルを、地図上で作成・編集するブラウザツール。

- 構成: HTML 1ファイル（`navhud-wp-editor.html`）。サーバー不要
- 動作環境: PC・スマホのブラウザ（Chrome 等）

---

## 1. 使用技術・外部サービス

| 種別 | 内容 |
|---|---|
| 地図ライブラリ | Leaflet 1.9.4（cdnjs から読み込み、BSD 2-Clause） |
| 背景地図 | 地理院タイル（標準／淡色／写真）。初期表示は「淡色」 |
| 住所・地名検索 | 国土地理院 住所検索API |
| 施設等の検索 | OpenStreetMap Nominatim（2段目、利用制限あり → 6章） |
| 標高 | 国土地理院 標高API |
| ブラウザ標準API | File API、TextDecoder、DOMParser、Blob、Clipboard（paste）、Geolocation、localStorage |

APIキーは不要。CSV の読み書き、距離計算（haversine）、元に戻すは自前で実装。

## 2. WPデータ

### 2.1 項目（CSVの列と同じ）

| 列 | 内容 | エディタでの入力方法 |
|---|---|---|
| lat / lon | 緯度・経度（10進、小数8桁で出力） | 地図で追加、マーカーのドラッグ、検索で移動して追加 |
| ele | 標高 [m] | 自動取得／↻ボタンで再取得／手入力 |
| name | WP名 | 手入力／検索結果の名前を自動入力 |
| target_time | 目標時刻 | 手入力（`1100` → `11:00` に自動変換） |
| deadline_time | 締切時刻 | 同上 |
| enabled | 有効／無効 | 「有効」チェック |
| radius | 到達半径 [m] | 手入力（空欄＝アプリの既定値） |

行の順番が案内順。

### 2.2 入力値の扱い

- 時刻: `1100`→`11:00`、`830`→`8:30`、`083000`→`8:30:00`。全角数字・全角コロンも可。`8:30` 形式はそのまま。時刻として成立しない値は赤枠表示
- 標高・半径: 数値でない値は赤枠表示（半径は 0 より大きい数）
- 標高は小数1桁まで（自動取得時）

## 3. ファイル入出力

### 3.1 読み込み（「読み込み」ボタン）

- **CSV**: 1行目の見出し名で列を判定。必須は `lat`,`lon`。文字コードは UTF-8 → 失敗時 Shift_JIS で自動判別。BOM 対応。`enabled` は `false`/`0`/`no`/`off` を無効、それ以外・空欄を有効。時刻列は 2.2 の変換を適用。座標が読めない行は除外し件数を通知
- **GPX**: `<wpt>` の lat/lon、`<name>`、`<ele>`、`<time>`（ローカル時刻の H:MM に変換して目標時刻へ）
- 読み込むと現在のWPリストを置き換える（元に戻すで復帰可）

### 3.2 書き出し（「書き出し」ボタン）

- CSV、見出し `lat,lon,ele,name,target_time,deadline_time,enabled,radius`、改行 CRLF
- 文字コード: UTF-8 BOM付き（初期値・Excel向け）／UTF-8 BOMなし
- `enabled`: 有効は空欄、無効は `false`
- カンマ・引用符・改行を含む値は引用符で囲む
- ファイル名は設定欄で変更可（初期値 `waypoints.csv`、CSV読み込み時はその名前を引き継ぐ）

## 4. 画面構成

画面幅 820px 以下をスマホ表示、それより広い場合をPC表示とする。

### 4.1 共通（地図画面）

| 位置 | 部品 |
|---|---|
| 左上 | 検索欄（入力・✕クリア・履歴・検索） |
| 右上 | 背景地図の切り替え（選ぶと自動で閉じる） |
| 右列 | 現在地／全体／戻す／タップ追加 ON・OFF／拡大・縮小（幅 54px、間隔 14px） |
| 中央 | 十字（追加位置） |
| 下部 | 選択中WPの編集パネル（選択時のみ）、追加ボタン |
| 右下 | 出典（Leaflet｜地理院タイル）、左下に縮尺 |

- PC: 地図の右に WPリストを常時表示。追加ボタン・編集パネルは最大幅 560px
- スマホ: 下部タブで「地図」「リスト」を切り替え。ツール類は「ツール・書き出し設定」に折りたたみ

### 4.2 地図上の表示

- マーカー: WP番号入りの丸。無効WPはグレー、選択中は黄色の枠
- 経路: 有効WPを順に実線で結ぶ。無効WPは前後の有効WPとグレーの破線で結ぶ
- 到達半径: WPごとの円（radius 空欄時は「既定半径」設定値、初期 30 m）
- 検索で移動した位置: 黄色の丸の目印

### 4.3 選択中WPの編集パネル（地図画面）

- 1行目: WP番号、名前、有効、削除、✕（選択解除）
- 2行目: 標高（↻付き）、半径、目標時刻、締切時刻

### 4.4 WPリスト

WPごとに3行のカード。

- 1行目: WP番号（押すと選択／解除）、名前、有効、削除
- 2行目: 標高（↻付き）、半径、目標時刻、締切時刻
- 3行目: 区間距離・累計距離（無効WPは「無効（案内しない）」、先頭は「出発点」）、「地図」（地図でそのWPを表示）、▲▼（並べ替え）

上部に選択状態、WP数（有効数）、総距離（有効WPのみ）を表示。

### 4.5 ツール・書き出し設定

- 元に戻す、空欄の標高を一括取得、全体表示、全削除（3秒以内に2回押しで実行）
- 地図タップで追加（初期 OFF。右列の「タップ追加」と連動）
- 標高を自動取得（初期 ON）
- 既定半径（初期 30 m、表示用。CSVには出力しない）
- ファイル名、文字コード
- OSM検索の状態（保存件数、直近3時間の使用回数）、「保存を消去」

## 5. WPの操作

### 5.1 追加

- **十字の位置に追加**: 地図を動かして十字を合わせ、追加ボタンを押す
- **タップ追加**（ON時のみ）: 地図をクリック／タップした位置に追加
- 追加位置: WP未選択なら末尾、選択中ならそのWPの直後
- 検索で移動した直後は追加ボタンが「＋「名前」を追加」となり、名前入りで追加

### 5.2 編集・削除・並べ替え

- マーカーのドラッグで位置変更（標高はクリアして自動再取得）
- 編集パネルまたはリストで各項目を編集
- リストの ▲▼ で並べ替え
- 削除・全削除・編集はすべて「元に戻す」の対象

### 5.3 標高

- 自動取得（ON時）: 追加・移動したWPの ele が空なら国土地理院から取得。1件ずつ順番に送信。手入力済みの値は上書きしない
- ↻ボタン: そのWPの標高を取り直して上書き
- 一括取得: ele が空のWPをまとめて取得（150ms 間隔）
- 海上・国外などデータのない地点は空欄のまま

### 5.4 元に戻す

- 変更前の状態を最大100件保持。右列「戻す」、設定の「元に戻す」、Ctrl+Z

## 6. 検索

### 6.1 検索欄の動作

入力内容に関わらず「候補を出して地図を移動するだけ」。WPを追加するかはユーザーが判断する。

| 入力 | 動作 |
|---|---|
| 座標（例 `34.69370, 135.50230`） | 1件ならその位置へ移動。複数行なら候補一覧 |
| 座標入りのGoogleマップURL | `!3d…!4d…`（ピン位置）優先、次に `@緯度,経度`／`?q=` を読んで移動 |
| 座標を含まないURL（短縮URL等） | 案内メッセージのみ |
| 地名・住所 | 2段構えで検索（6.2） |

- 入力欄以外の場所で座標を貼り付け（Ctrl+V）た場合も同じ動作
- 候補を選ぶと、拡大段階 14 でその位置へ移動し目印を表示

### 6.2 2段構えの検索

1. **国土地理院**で検索し、候補一覧を表示（1件でも一覧表示）
2. 一覧の上部の「OSMでも探す」を押すと **OSM（Nominatim）**で検索
3. 国土地理院が 0件のときは自動で OSM も検索
4. OSMの結果を上、地理院の結果を下に並べる

- 印: 「地理院」（青）、「OSM」（紫）、「座標」（灰）
- 一覧の最下部に出典を常時表示（検索: 国土地理院／© OpenStreetMap contributors（Nominatim））

### 6.3 OSM（Nominatim）の利用制限

無料の公開サーバーのため、ブラウザ内で以下の制限をかける。

- 検索はボタン押下時（または地理院 0件時）のみ。1文字の語句は送らない
- 送信間隔 2秒以上、同時に1件まで
- 3時間で30回まで（超えたら地理院のみ）
- 429／403 応答時は3時間停止
- 結果は30日間保存して再利用（「保存を消去」で削除可）

### 6.4 検索履歴

- 「履歴」ボタンで一覧表示。選んだ候補を新しい順に最大30件保存（同じ場所は重複させず先頭へ）
- 項目を選ぶと検索せずに即移動（APIへの問い合わせなし）
- 「履歴を消去」で削除
- 一覧の最下部に、履歴に含まれる検索先の出典を表示

## 7. 軌跡の表示

GpsLogger の軌跡を地図に重ねて表示する（表示のみ。WPリスト・CSVには影響しない）。

- 右列の「軌跡」ボタンでメニューを開く（読み込み／非表示・表示／全体／消去）
- 読み込める形式: GpsLogger のエクスポートZIP、または track.csv 単体
- ZIP は `session_YYYYMMDD_HHMMSS/track.csv` だけを読む。複数セッションなら一覧から1つ選ぶ（開始日時・時刻範囲・点数・区間数・距離を表示）
- 列は名前で引く（必須: `epoch_ms`, `latitude`, `longitude`、任意: `gap_before`）
- `gap_before=true` の点で区間を分け、区間の間は線でつながない。測位の途切れ（トンネル等）はつなぐ
- 表示: 1本のみ。WPの線より下に描画。●始点 ○終点
- ブラウザには保存しない（開き直したら再読み込み）

## 8. ブラウザ内の保存（localStorage）

| キー | 内容 |
|---|---|
| `navhud-wp-draft` | 作業中のWPリスト（変更のたびに自動保存、起動時に復元） |
| `navhud-search-hist` | 検索履歴（最大30件） |
| `navhud-osm-cache` | OSM検索結果の保存（30日） |
| `navhud-osm-state` | OSMの送信記録（直近3時間）と停止解除時刻 |

- 保存はそのブラウザ内だけ。サーバー送信・端末間共有なし
- 開く場所（ローカルファイル／GitHub Pages）が違うと別の保存先になる
- 残したいWPは CSV に書き出して保管する
